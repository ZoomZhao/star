# 整体 Review · 2026-09-08

检查范围：服务端角色/家庭边界、任务规则与每日快照、提交/审核/兑换/撤销、JSON 备份恢复；Web 登录、异步加载、日期刷新与网络重试；Android 原生加载、登录清理、持久化操作编号及现有横屏界面。

## 已修复

1. **未来任务预览冻结旧模板。** 先看明天、再修改模板时，旧任务仍然存在。现在修改模板会在同一事务中清除未来未提交且未经单日修改的预览；下次读取按最新模板生成。当天、历史、提交记录和家长明确编辑的单日规则保留。停用和重复安排变化同样生效。
2. **不确定的服务器响应可能导致重复记账。** Web/Android 收到 5xx 后仍保留操作编号；Web 改用持久化存储，刷新、重新打开后也可安全重试。成功或明确的客户端错误后释放编号。服务器拒绝同一个编号对应不同内容；已成功兑换即使奖励下架也能返回原结果，跨日重试成功的任务提交也返回原记录。
3. **备份引用存在但业务归属错误仍能恢复。** 增加孩子角色、家庭、操作人权限、审核状态、流水金额与来源、撤销关系、次数上限及任务安排校验。所有校验先在临时数据库完成；拒绝无效备份时不改在线数据、不注销会话、不生成恢复前备份。合法的已审批/已撤销记录仍可恢复。
4. **首次加载家庭信息失败后刷新无效。** Web 和 Android 均重新加载家庭与模板；Web 将加载失败与未分配孩子分开展示。Android 恢复成功后清除错误，退出时清理家庭数据和滚动缓存。
5. **Web 登录和日期状态滞留。** 其他标签页退出/切换账号时同步刷新；过时的 401 不再清除新会话；旧家庭请求不再覆盖当前账号。打开的“今天”页面在上海时间跨日后更新，手动选择的历史日期保留。
6. **任务提交计数反复扫描提交表。** 增加 `(task_id, status)` 索引，服务现有任务计数、规则冻结及提交记录查询，无数据迁移。

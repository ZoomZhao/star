# NFC 实体任务卡试用

适合家长使用支持 NFC 的安卓手机：孩子完成任务后拿到对应实体卡，交给家长碰卡确认，星星进入现有账本。当前版本为 Android 0.3.1-native：手机亮屏解锁后，碰任务卡可打开 App；进入扫描页后保持贴卡，必要时移开再碰，读卡成功后发星并播放动画。同一张实体卡每天只发星一次，之后可以修改本次积分。需同步更新服务端的同卡每日去重接口，无数据库结构迁移。

## 先购买这些

| 物品               | 试用数量 | 采购要求                                                                                      |
| ------------------ | -------- | --------------------------------------------------------------------------------------------- |
| NFC 空白白卡       | 10 张    | NTAG213 优先，NTAG215 / 216 也可；13.56MHz；NFC Forum Type 2；已格式化为 NDEF；可擦写、未锁定 |
| 普通贴纸或姓名标签 | 1 包     | 写孩子姓名和任务名称，直接贴在白卡上                                                          |
| 收纳盒或卡袋       | 2 个     | 分别存放“待确认”和“已确认”卡片，家中现有物品即可                                              |

电商搜索词：**NTAG213 NFC 空白白卡 NDEF 可擦写 10张**。下单前让卖家确认“安卓手机可直接读写 NDEF”，先购买小批量样品。首轮物品预算建议控制在 50 元以内，这是预算上限建议，非实时报价。

NTAG213 / 215 / 216 的用户容量分别是 144 / 504 / 888 字节，均符合 NFC Forum Type 2 和 ISO14443-A。本版任务卡只保存孩子编号和固定任务编号，一条 NDEF 记录小于 144 字节，NTAG213 足够。[NXP 官方规格](https://www.nxp.com/products/NTAG213_215_216)

购买时避开 125kHz ID 门禁卡、已锁定卡、未说明芯片的“IC 卡”。手机就是读写器，无需额外购买 USB 读卡器、专用终端或打印机。请勿直接用普通喷墨打印机打印 PVC 白卡；手写贴纸即可完成首轮试用。

## 第一次制作

1. 安装新版 Android 包，用家长账号登录，打开手机系统 NFC。
2. 进入“规则”，选择孩子及科目，在对应任务下点击“制作 NFC 任务卡”。
3. 核对孩子和任务，点击“开始写卡”，把一张空白卡贴近手机 NFC 感应区，保持到出现“任务卡制作成功”。
4. 在卡面贴上“孩子姓名 · 阅读”等标签。点击“检测这张卡 · 不发星”并再次碰卡，先核对绑定信息。孩子实际完成任务后再从今日任务进入“碰任务卡 · 自动发星”，此时碰卡直接到账。
5. 先制作阅读、运动、作业等 3–5 项常用任务，再按实际需要增加。

App 会校验写入结果；卡中已有其他内容时拒绝覆盖。如需更换用途，先用 NFC 工具明确清空该卡，再重新制作。本版要求已具备 NDEF 格式的卡片，未格式化卡片需要先用 NFC 工具格式化。

## 担心卡片混淆时

打开“更多 → 检测卡片”，一次贴近一张卡。检测页不会发星，会显示孩子、科目、任务名称、最新规则启停状态及当天星星和上限，以及实体卡编号、今天是否已确认；名字可选中复制，建议照着写到卡面。同任务多张卡可以标为“阅读 A / B / C”，卡号用于区分实体卡。移开再碰下一张，可以连续核对。自动发星页也有检测入口，切换时停止原扫描。

这是独立只读模式：不发星、不审核已有提交、不增加完成次数、不生成每日快照，也不改写卡片。空白卡会显示“还没有绑定任务”；今天未安排或规则停用的任务卡仍能检测。改名从明天生效时，分别显示最新规则名称和今日快照名称；其他家庭的卡不会泄露绑定信息。检测需联网查询任务名称。

## 不提前打开 App，也能碰卡发星

1. 安装新版并使用家长账号登录一次；保留登录，开启手机 NFC，保持联网。
2. Android 16 可在 App“设置 → 允许 NFC 唤起应用”打开系统设置，为“星星探险家”允许通过 NFC 启动；系统入口通常在“设置 → 应用 → 特殊应用权限 → 通过 NFC 启动”，厂商名称可能不同。
3. 回到手机桌面，保持亮屏并解锁，把一张任务卡靠近背面。安卓会识别现有 `star-task://v1/...` 卡片并打开 App；恢复家长登录、进入扫描页后保持贴卡，必要时移开再碰，读卡成功后自动确认积分并显示到账动画。已有任务卡无需重新制作，也不需要额外安装自动化工具或常驻后台服务。
4. 若首次弹出应用选择，选择“星星探险家”，系统提供“始终”选项时可选中。尚未登录或登录已失效时不会发星；登录完成后需重新碰卡，旧卡请求不会跨登录继续执行。

本版按亮屏、解锁的使用方式设计，不承诺熄屏或锁屏自动唤起。若系统中强行停止了 App，先手动打开并检查 NFC 启动开关再试。外部 NFC 启动消息仅打开扫描页，不能直接发星；进入页面后保持贴卡，必要时移开再碰。实际读卡由系统前台读取回调触发，现场读取卡片内容与 UID，再执行每日去重和任务上限检查。普通网页、URI 点击或伪造启动消息不能替代这一步。App 重建或从最近任务恢复不会重新消费旧的启动标签。

**检测模式优先保留**：如果 App 停在“检测卡片”页，即使切到桌面再碰卡唤起，也只显示绑定信息，不会发星。需要恢复自动发星时，先点“返回任务”退出检测页。当前有编辑窗口或其他操作正在进行时，会提示完成操作后重新碰卡。

系统分发、解锁条件与 Android 16 的 NFC 启动许可见 [Android NFC 基础知识](https://developer.android.com/develop/connectivity/nfc/nfc)；系统设置入口依据 [NfcAdapter ACTION_CHANGE_TAG_INTENT_PREFERENCE](https://developer.android.com/reference/android/nfc/NfcAdapter#ACTION_CHANGE_TAG_INTENT_PREFERENCE)。

## 每天怎样用

1. 孩子完成任务后领取对应的卡，放入“待确认”盒。
2. 家长打开“今日任务 → 碰任务卡 · 自动发星”，一次拿一张卡贴近手机背面。
3. 界面自动找到对应孩子及当天任务，直接按当天快照的默认星星确认，立即播放到账动画，不用再点击确认。
4. 需要调整时，点最近一次到账的“修改本次积分”，选择修改后的总积分并保存；重启 App 后仍可查看最近记录，也可在星星账本修改任务收入。
5. 成功后收回卡片，放入“已确认”盒；App 会继续等待下一张卡。同一张实体卡在同一个家庭内，每个北京时间自然日只确认一次；当天移开再碰也只提示“今天已确认”，不发星、不重复动画。次日零点后归位重复使用。

如果孩子已经在 App 提交这项任务，刷卡会优先审批当天最早的一条待审核提交，不额外创建一次完成；没有待审核提交时走现有“家长代完成”流程。今天未安排或次数已用完的任务不能通过卡片增加完成次数。

经常重复完成的任务可以给多张实体卡写入同一个任务。例如每日上限为 3 次的阅读任务，制作 A、B、C 三张阅读卡；分别碰卡各确认一次，A 重复碰卡不会增加次数。每张新卡记录 1 次新完成；已有待审核提交时确认该提交原有次数。多张卡仍然对应同一个任务，不能同时叠在感应区。现有上限不会自动提高：任务每日最多 1 次时，多张卡也最多确认 1 次。规则修改从明天生效；今天继续使用当天快照。需要手动记录多次时，可继续使用原有任务页操作。

## 规则与数据

- 卡片是可重复使用的任务标识。只有已登录家长进入碰卡页后才会自动发星，卡片不保存密码、登录令牌或星星余额。
- 卡片绑定固定任务编号，不绑定某个规则版本、任务名称或星数。修改名称、科目、星星、上限后，无需重写卡；结算依照任务归属日期的快照。模板修改从明天生效，今天仍可能显示旧快照。
- 不增加、重建或重置孩子的默认任务，不修改既有规则、每日任务快照、账号或账本结构。审批和代完成继续由服务器检查家庭权限、次数上限及重复请求。
- 使用卡片自身的 NFC UID 区分实体卡，已写好的任务卡无需重写。同一家庭、同一天的卡片使用状态由服务器保存，换家长账号、重启 App、修改积分、撤销到账或重写任务都不会让当天已确认的卡重新可用。识别与发星仍需家长登录，并受任务上限约束；这不是防复制卡的安全凭证。丢卡后可补写同一任务卡，新卡不会使旧卡失效。
- 任务卡首次到账的账本记录使用固定 UUID v5，按家庭、北京时间日期与实体卡 UID 生成；原记录保留，完整备份恢复后仍能识别已用卡。命名空间与格式属于持久化协议，不可随意更改。升级前没有采集卡片 UID 的历史到账无法追溯到实体卡，新规则从升级后首次碰卡开始记录。
- App 内碰卡页使用前台读卡；在桌面或其他应用时，系统可通过任务卡的 NFC 事件唤起 App。两种方式都需要家长登录并联网确认。锁屏或进入后台时停止 App 自己的读写会话；本版按亮屏解锁使用。普通不支持 NFC 的平板继续使用原有任务操作。

## 修改本次积分

“修改本次积分”调整的是这一笔的总星星（1–2020），不更改默认规则、任务快照、原提交的星数或完成次数。账本原记录保留，服务端在同一事务中追加全额撤销与新积分；修改后的记录仍可再次修改。原日期的今日获得、累计获得与七日统计按最新积分计算，不把纠正记录重复计入。减少积分时检查最终余额，余额不足会全部回滚。

要取消发星，可在星星账本撤销最新到账；撤销积分不释放已完成次数，也不释放这张卡今天的使用状态。

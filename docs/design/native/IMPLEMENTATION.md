# 原生 Android 设计落地

ImageGen 原稿：`princess-tablet-reference.png`。两套场景皮肤：恐龙探险 / 公主花园。科目插画原稿与提示词见 `../subjects/`。

- Activity + Android Views 负责布局、按钮、日期选择、对话框、输入、科目和区域滚动。
- ArtView 用 Canvas 绘制打包在 APK 中的 ImageGen WebP，位图使用有上限的缓存。
- SparkleView 使用原生 ValueAnimator 播放短星星动画；触感使用系统反馈。
- StarView 以原生 Canvas 绘制金色渐变、高光和描边星星，应用于余额胶囊、任务星槽、四段收集进度和每日汇总。任务槽代表完成次数：仅审核通过点亮，待审核显示时钟；上限超过 5 次时收拢为星星图标与明确次数。成长节点根据当日星星上限分成四段，不额外发奖。
- 横屏按窗口可用宽高计算，不使用 ScrollView 包裹整个首页；任务筛选下方独立滚动，日期、科目和导航固定。小铺商品、历史流水与管理列表各自滚动。
- Skin 决定颜色和场景资源；分类图片独立于皮肤，切换主题不会改变任何业务记录。
- StarApi 用 HttpURLConnection 请求 HTTPS API；提交、兑换、记账复用持久化幂等编号。
- SessionStore 使用 Android Keystore AES-GCM 加密令牌，不保存密码。
- 系统文件选择器负责备份导出与恢复文件选择。

0.2.1-native 已在 DMG-W00（2800×1840）安装。金色星星实机截图见 `docs/screenshots/native-gold-stars-landscape.png`，四任务按钮和主要汇总同屏可见。构建与 2 项布局计算测试通过；隔离 API 的提交、审核、发星和规则编辑 Espresso 流程通过。另一条流程通过了登录、原生布局及四按钮完整可见断言，但在点击英语分类时因当前根窗口为账号设置对话框而失败，后续换装与重建断言尚未通过。

测试工具结束时自动卸载了应用，清除了设备本地登录。已重新安装 0.2.1-native 并恢复公主皮肤偏好，需要用户重新登录；服务端账号和业务数据不受测试影响。今后 Gradle connected 测试仅用于专用测试设备或模拟器。

## 0.2.2-native 完成任务动画

- “我完成啦”按下缩放、释放回弹；确认面板的大金星弹入并轻转，保留原有备注和确认步骤。
- 服务端提交成功后播放约 2.6 秒的弧线飞星、扩散光环、双色星屑和成功卡片。儿童文案为“任务已提交 / 等待家长确认”，不提前修改余额。家长完成或任务审核通过显示发星成功；退回不播放庆祝。
- 特效放在独立原生视图层，刷新任务数据不会移除动画。效果不拦截触摸，结束或进入后台即清理；关闭系统动画时仅短暂展示静态结果卡片。
- 修复 StarView 绘制阴影后透明度未复位，导致金色填充偏淡的问题。
- DMG-W00 实机的 CompletionAnimationTest 通过：两种皮肤、连点不重复提交、待审核余额不变、刷新后动画保留及播放后自动清理。使用 `-PisolatedTestApp` 独立包名和内存 API，与用户应用分开。截图见 `docs/screenshots/completion-princess-burst.png`。
- 已覆盖安装正式包名的 0.2.2-native，更新前后均直接进入“吞吞的星星日”，公主皮肤和四张任务卡保留。测试包与转发端口已清理。

## 0.2.3-native 三页统一优化

- 内置 ImageGen 生成首页、宝库、小铺新稿，以及导航和奖励插画图集。完整提示词与文件位置见 `REFINEMENT-PROMPTS.md`。
- 顶部中间显示当日已获星星，宝库/小铺显示当前页标题；去掉当日可得总数和每日分页。日期与页面标题合并，释放任务区域高度。
- 连续式导航栏使用两套皮肤的插画图标、柔和选中背景与位置指示线；收集之旅变为金色星轨纪念卡，不再显示配额进度。
- 每日任务按科目独立滚动，切换科目回到顶部；返回页面和数据刷新保留当前滚动位置。任务、流水与商品滚动容器互不影响。
- 宝库采用左侧余额/累计收支/七天趋势，右侧独立流水；小铺在宽平板使用三列插画卡。奖励价格、编辑、上下架和审核逻辑保持原有规则。
- 修正像素到 dp 换算中的提前取整，避免 2.5 倍密度平板误进入较窄布局。
- Android 15 模拟器按 2800×1840、400 dpi 验证：RefinementTest 两项流程通过（含完成动画回归）；最终文字对齐调整后页面流程再次通过。覆盖两套皮肤、科目筛选、局部滚动、固定控件位置、返回时的滚动位置、家长管理入口、连续点击不重复提交和待审余额不变。截图以 `docs/screenshots/refined-` 开头，使用隔离测试数据。
- 正式包名 APK 0.2.3-native 已构建。DMG-W00 锁屏，覆盖安装尚未完成；等待用户解锁。等待中的旧安装会话已取消，设备仍保留 0.2.2-native 与其登录数据。

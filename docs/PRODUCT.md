# 星星探险家 · 产品约定

- Android（手机 / Pad）使用原生 Android Views / Canvas / HTTPS 客户端，Web 使用 React，两端共用服务端业务规则。
- 五科分类：语文、数学、英语、体育、其他，每类两个预制子任务；家长可新增、修改、停用任务。科目随具体任务规则一起保存快照。
- 原生横屏固定导航、场景、日期和科目；筛选后的任务在右侧区域上下滚动，取消分页。顶部显示当日已获得星星，不显示当日可得总数。星星宝库的流水、小铺的商品分别独立滚动。
- 登录令牌持久化，Android 用 Keystore 加密，Web 保存在 localStorage。180 天未使用过期，日常使用续期；退出、改密、停用或恢复后重新登录。
- 管理员提前创建家庭和账号；家长仅管理本家庭；孩子只访问自己。无公开注册。设置页保留退出 / 更换账号入口。
- 家长制定每日、每周、指定日期规则。任务为指定日期保存完整快照：名称、科目、说明、每次星数、次数上限、图标、规则来源版本。
- 修改模板从明日起生效。未来日期的自动预览随模板更新，今天和历史快照保持不变；家长单独修改过的单日规则优先保留。已有提交的任务规则冻结。
- 孩子每次完成产生一条待审核记录；待审核与已通过次数共同占用上限。退回可重新提交。
- 家长审批或代完成才发星。审批、上限和流水在同一数据库事务中处理；客户端幂等键防止网络重试重复记账。
- 星星流水不可修改或删除；错误通过反向流水撤销。余额不能为负；星星不过期。任务取消不自动扣星。
- 家长可发奖励、扣星、记录购买；孩子可申请兑换，审核通过才扣星，余额不足时拒绝结算。
- 奖励由家庭共用，家长可新增、编辑、下架及重新上架；家长可见全部状态，孩子只见已上架奖励。下架不删除既有兑换申请，修改不改变申请中的名称和星星价格快照。
- 首页展示当日可得、已获得、待审核和余额。汇总显示历史收入、支出、余额和每日明细。
- 日期以 Asia/Shanghai 自然日计。孩子仅能提交当天任务；家长可代完成过去任务。无需离线提交。
- 数据使用 SQLite 单文件数据库。超级管理员下载版本化 JSON 完整备份（含账号密码哈希，不含登录会话），恢复时校验结构与关系，在事务内替换数据，恢复前保存当前备份，恢复后全部重新登录。
- 视觉面向 5–10 岁，提供恐龙探险、公主花园两套皮肤。设计先通过 ImageGen 生成，再用真实组件还原，图片不作为交互页面。
